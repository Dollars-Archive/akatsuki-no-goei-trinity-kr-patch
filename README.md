## 게임 소개

**새벽의 호위 트리니티**는 본편, 팬디스크, 완결편을 한 패키지로 묶은
선택지 중심의 비주얼 노벨입니다.

치안이 악화된 근미래 일본, 보디가드를 양성하는 학원에서
능력을 숨기고 지내던 아사기리 카이토가 영애 니카이도 레이카의 호위를 맡게 됩니다.
학원에서의 일상과 인물들의 만담으로 시작한 이야기는
금지구역과 카이토의 과거를 둘러싼 사건으로 이어집니다.

### 수록 작품

- 본편 **새벽의 호위** — 暁の護衛
- 팬디스크 **프린시펄들의 휴일** — 暁の護衛～プリンシパルたちの休日～
- 완결편 **죄깊은 종말론** — 暁の護衛～罪深き終末論～

### PS3판 특징

- 세 작품을 하나로 묶은 구성
- HD 그래픽과 트로피 지원
- 신규 이벤트 그래픽과 오프닝·주제가
- 백로그, 메시지 스킵과 표시 속도 설정
